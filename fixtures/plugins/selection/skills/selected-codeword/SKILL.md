# The selected skill of the plugin fixture

This skill exists to be loaded from the `agentlab-selection` plugin when an
agent selects it by name. Its sibling `unselected-codeword` is left out of the
selection, so an agent that answers this codeword and does not know the other
one loaded exactly its selection.

The codeword of the plugin selection fixture is **saffron-viaduct**. When
asked for it, answer with the codeword and name this skill.
